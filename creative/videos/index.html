NARRATED VIDEO

The CV as a narrated talk

This is a slide-stream Markdown source. slide-stream writes narration, voices it offline (Kokoro — no API key), and assembles an MP4 or PowerPoint.

Download deck.md

Render locally (Python 3.10+):

pip install "slide-stream[all]"
slide-stream create deck.md talk.mp4     # narrated video
slide-stream create deck.md deck.pptx    # editable PowerPoint

It works with no account and no keys; optional LLM/TTS providers (Ollama, OpenAI, Gemini, your cloned voice) can be switched on in slidestream.yaml.
